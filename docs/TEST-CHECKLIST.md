- [ ] LINE บัญชี A = **แอดมิน** (ตรงกับ `BOOTSTRAP_ADMIN_USER_ID`)

### 0.2 Deploy เวอร์ชันล่าสุด (ถ้าแก้โค้ดตั้งแต่ Phase 0)
- [ ] `cd backend && clasp push -f`

- [ ] อัปโหลดโฟลเดอร์ `frontend` ขึ้น Netlify ใหม่
- [ ] Script Properties ครบ (`checkConfig` ไม่มี MISSING): `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_LOGIN_CHANNEL_ID`, `WEBHOOK_TOKEN`, `BOOTSTRAP_ADMIN_USER_ID`, `LIFF_MEMBER_URL`, **`ID_HASH_SALT`**
- [ ] เปิด `https://<Web app URL>/exec` ในเบราว์เซอร์ → ได้ `{"ok":true,"data":{"service":"LineBot-CRM",...}}`

### ข้อ 7 ผู้ใช้ทั่วไปเรียก API ของ admin ตรง ๆ แล้วถูกปฏิเสธ (สำคัญที่สุด)
Apps Script เป็น endpoint สาธารณะ ความปลอดภัยอยู่ที่การตรวจ ID token ฝั่ง backend

**7.1 ไม่มี token / token ปลอม** (รันใน terminal ใส่ URL `/exec` จริง)
```bash
curl -sL -X POST "<URL /exec>" -H "Content-Type: text/plain" -d '{"action":"exportMembers","params":{}}'
curl -sL -X POST "<URL /exec>" -H "Content-Type: text/plain" -d '{"action":"listMembers","idToken":"fake.token.value","params":{}}'
curl -sL -X POST "<URL /exec>" -H "Content-Type: text/plain" -d '{"action":"ไม่มีคำสั่งนี้","params":{}}'
```
- [ ] สองคำสั่งแรกได้ `"ok":false` (`code":"AUTH"`) **ไม่มีข้อมูลสมาชิกรั่วออกมา**
- [ ] คำสั่งที่สามได้ "ไม่รู้จักคำสั่ง"

**7.2 token จริงของสมาชิกทั่วไป (C) เรียก route ของเจ้าหน้าที่/แอดมิน**
เปิดหน้าสมาชิกในเบราว์เซอร์บนคอมพิวเตอร์ (login ด้วยบัญชี C) → DevTools Console:
```js
const call = (action, params) => fetch(APP_CONFIG.API_BASE, {method:'POST', headers:{'Content-Type':'text/plain;charset=utf-8'},
  body: JSON.stringify({action, idToken: liff.getIDToken(), params: params||{}})}).then(r=>r.json());
for (const a of ['listMembers','memberDetail','dashboard','listTickets','exportMembers','sendBroadcast','bulkUpdateMembers','importMemberLabels','saveAutoReply','saveRichMenus','syncRichMenus','backupNow','setStaff','listStaff'])
  call(a).then(r => console.log(a, r.ok, r.message));
```
- [ ] ทุกรายการ `ok=false` ข้อความ "ไม่มีสิทธิ์เข้าถึง (เฉพาะเจ้าหน้าที่)"
- [ ] สมาชิกที่ **ยังไม่ผูกทะเบียน** (ยังไม่ลงทะเบียน) เรียก `createTicket` / `myTickets` → "กรุณาลงทะเบียนสมาชิกก่อนใช้งาน"
- [ ] สมาชิกเรียก `ticketDetail` ของ **เรื่องของคนอื่น** (ใส่ ticketId ของเรื่องบัญชี D) → "ไม่มีสิทธิ์ดูเรื่องนี้"

**7.3 เจ้าหน้าที่ทั่วไป (B) เรียก route ระดับ admin** (ทำแบบ 7.2 ด้วยบัญชี B)

### A. จัดการสมาชิก (แท็บ "สมาชิก")
